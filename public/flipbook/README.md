# Flipbook assets

- `pdf.worker.min.mjs` — pdf.js worker (copied from `pdfjs-dist`; re-copy after upgrading that package)
- `turn.mp3` — page-turn sound
- Institute brochures — configured in `lib/brochure.ts` (`name` + `pdfUrl`)

Drop PDFs here (e.g. `data-analysis.pdf`) or point `pdfUrl` at any absolute URL.
